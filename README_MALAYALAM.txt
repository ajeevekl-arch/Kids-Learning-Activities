Kids Learning Activities - Android Studio Project

ഉൾപ്പെടുത്തിയ പ്രവർത്തനങ്ങൾ PDF-ൽ നിന്നുള്ള ആശയങ്ങൾ അടിസ്ഥാനമാക്കിയാണ്:
Up/Down, Left/Right, Clockwise/Anti-clockwise, Colouring, Same/Different,
In/Out, Near/Far, Open/Closed, Big/Small, Short/Tall, Heavy/Light,
Thick/Thin, Long/Short, Number Learning & Tracing.

Android Studio-യിൽ തുറക്കാൻ:
1. ZIP extract ചെയ്യുക.
2. Android Studio > Open > Kids_Learning_Activities_Android_Studio ഫോൾഡർ തിരഞ്ഞെടുക്കുക.
3. Gradle Sync പൂർത്തിയാകാൻ കാത്തിരിക്കുക.
4. Run അമർത്തുക, അല്ലെങ്കിൽ Build > Build APK(s).

കുറിപ്പ്: ഇത് ആദ്യ പ്രവർത്തിക്കുന്ന UI prototype ആണ്. ചിത്രങ്ങൾ ഇപ്പോൾ emoji/illustration placeholders ആണ്;
പിന്നീട് PDF-യിലെ യഥാർത്ഥ worksheet artwork ഉപയോഗിച്ച് കൂടുതൽ കൃത്യമാക്കാം.
Internet permission/API key ആവശ്യമില്ല.
